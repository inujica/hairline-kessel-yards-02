HAIRLINE: Kessel Yards — a round-based tactical FPS in three.js, played in the browser: two teams of five, a breaker to plant and defuse, money between rounds and a buy menu, headshots with damage falloff, and bots that path the lanes, hold angles and fight what they can see.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. The game is static files under `game/`, ES modules with three.js 0.187.0 vendored and mapped through an import map: no build step, no network request.
